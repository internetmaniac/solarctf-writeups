# Нулевой отчёт

**Категория:** Cryptography
**Флаг:** `SOLARCTF{y0u_h4sh3d_th3_wr0ng_th1ng}`

## Дано

Сервис `nc solarctf.ru 30102` под названием "Zero Report". Легенда от первого лица: "Я написал аудитор: если он одобряет программу, в её отчёте точно одни нули. Проверил на своих тестах, всё проходит. Сможешь доказать, что я неправ?"

По протоколу нужно прислать одной строкой base64 программу на Python, сервис ее проверит и либо пришлет флаг (если аудит "одобрил" программу, но при этом отчет не нулевой — то есть поймал баг аудитора), либо `REJECT`.

## Что за аудитор на самом деле

Сервис не выполняет присланный код как обычный Python через `exec`, а сам руками обходит AST и вычисляет значения по очень узкой грамматике. Разрешено только:

- функция `generate()` с 1-32 простыми statement внутри;
- присваивания вида `имя = выражение`, где выражение это целочисленный литерал, имя ранее объявленной переменной, специальное имя `P` (равно `2**127 - 1`), или вызов `H(SOURCE)`;
- арифметика `+ - * %` с ограничением на битовую длину промежуточных значений;
- последняя строка обязательно `return [a, b]`.

Отдельно присланный код должен быть побайтово равен тому, что получится, если взять только тело `generate()` и обернуть его официальным шаблоном из `pack.py` (авторский скрипт, который генерирует "каноническую" обертку с хэш-функцией и служебной самоссылающейся строкой `SOURCE`). То есть руками редактировать обертку нельзя, только тело функции, а дальше `pack.py` собирает итоговый файл.

Ключевая деталь — `H(SOURCE)`. В грамматике это не настоящий вызов функции, а просто синтаксический маркер: сервис видит `H(SOURCE)` как AST-узел и напрямую подставляет вместо него `source_hash`, заранее посчитанный как SHA-256 от **всего присланного файла целиком**, по модулю `P`. То есть собственная программа может сослаться на хэш самой себя прямо в вычислениях, и сервер гарантированно подставит то самое значение, которое использует и для своей проверки.

## Условие принятия отчета

Функция `audit()` на стороне сервиса делает так:

```python
accepted = (
    0 <= a < P and 0 <= b < P
    and (a != 0 or b != 0)
    and ((1 - source_hash) * a + source_hash * b) % P == 0
)
```

где `a, b` это то, что вернула `generate()`, а `source_hash` (обозначим `h`) это тот же самый хэш всего файла по модулю `P`.

Идея автора была в том, что раз `h` заранее неизвестен (зависит от содержимого самой программы, "курица и яйцо"), угадать пару `(a, b)`, удовлетворяющую этому линейному уравнению, без перебора нельзя. Но раз программа имеет доступ к `h` через `H(SOURCE)` прямо во время вычисления отчета, задача превращается не в перебор, а в чистую алгебру.

## Эксплойт

Уравнение `(1 - h)*a + h*b ≡ 0 (mod P)` это одно линейное уравнение с двумя неизвестными при известном (пусть и заранее непредсказуемом, но доступном в момент вычисления) `h`. Для него сразу видно тождественное решение, которое выполняется при любом `h`:

```
a = h
b = h - 1
```

Подставляем: `(1 - h)*h + h*(h - 1) = h - h^2 + h^2 - h = 0`. Тождество, выполняется всегда, независимо от конкретного значения `h`. Единственное, что нужно проверить дополнительно, это что `a != 0` (то есть `h != 0`, что для SHA-256 практически гарантировано) и что оба значения лежат в `[0, P)`, что тоже выполняется автоматически, раз `h` уже взято по модулю `P`.

Тело `generate()` получилось на две строки:

```python
def generate():
    a = H(SOURCE)
    b = a - 1
    return [a, b]
```

Прогоняем это тело через `pack.py`, чтобы получить канонический файл побайтово в нужном формате, кодируем результат в base64 и отправляем на `nc solarctf.ru 30102`. Отчет `[a, b]` ненулевой почти наверняка (оба значения завязаны на реальный хэш файла), условие принятия выполняется как тождество, сервис выдает флаг.

## Вывод

Отсюда и название таска и сам флаг: "ты захэшировал не то". Автор аудитора хотел защититься хэшем от предсказуемости, но дал атакующей программе доступ к значению этого самого хэша прямо в момент вычисления отчета. Как только в уравнении появляется легальный способ подставить `h` как значение, а не как что-то скрытое, обычная линейная алгебра по модулю простого числа тут же находит тривиальное тождественное решение, без перебора и без взлома самого SHA-256.

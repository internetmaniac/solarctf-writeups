# Вентилятор-303

**Категория:** Misc / радио-стего
**Флаг:** `SOLARCTF{YuG0sl4v1a-Galaks1ja-DIY-Z1L0G80Z}`

## Дано

Файл `ventilator303.wav`. Название явно отсылает к старой югославской радиопередаче "Ventilator 202" (Radio Belgrade), что сразу намекает на нужную эпоху и регион, пригодилось позже при сборке самого флага.

## Разбор сигнала

На слух и по спектрограмме видно, что это не голос, а модемный сигнал, похожий на FSK (frequency-shift keying). Подбором частот выяснилось: это стандартная для той эпохи схема 1200 бод, где 1200 Гц кодирует 0, а 2400 Гц кодирует 1. На семплрейте 44.1 кГц один бит занимает примерно 36.75 сэмпла.

Первая попытка демодулировать через обычный zero-crossing (считать переходы через ноль и мерить период) не сработала: в сигнале есть фазовые скачки, из-за которых таймингом по пересечениям нуля ловится мусор. Решение: вместо тайминга брать фиксированное окно под один бит и коррелировать его отдельно с чистым тоном 1200 Гц и с чистым тоном 2400 Гц, какая корреляция больше, тот бит и есть. Это устойчиво к фазовым прыжкам, потому что не зависит от точного момента перехода.

Биты собираются в байты по стандартной схеме 8N1 (один старт-бит, 8 бит данных, стоп-бит), причем кадру предшествует лид-ин байтами `0x55` (чередование 0101), что в демодуляции служит дополнительным ориентиром для синхронизации.

## Что внутри

После демодуляции получается не случайный мусор, а структура:

- текстовый заголовок `VENTILATOR-303 TAPE v1`
- поле `FORMAT ZXTAP`
- контрольная сумма `CSUM`, которая оказалась CRC16-CCITT с initial value `0xFFFF`
- и дальше, собственно, образ ленты в формате ZX Spectrum TAP.

То есть сигнал кодирует кассету для ZX Spectrum, записанную через аудио, как оно и делалось в реальности на тех магнитофонах.

## Разбор TAP и Z80-кода

В TAP-файле есть блок CODE, загружаемый по адресу `0x8000`. Дизассемблирование (SkoolKit, у него есть чисто Python реализация `sna2skool`, что удобно без лишних зависимостей) показывает, что код:

1. генерирует псевдослучайную последовательность через классический ANSI C LCG (`x = x * 0x41C64E6D + 0x3039`), засеянный значением из ячейки `$83D4`;
2. на каждый байт шифротекста XOR-ит биты 16-23 текущего состояния генератора;
3. раскладывает получившиеся символы флага по экрану не по порядку, а через таблицу позиций, лежащую по адресу `$83D8`.

Реализовал тот же LCG и ту же таблицу позиций в Python, прогнал по зашифрованным байтам и восстановил флаг, собрав символы в правильном порядке по таблице.

## Вывод

Задача на несколько слоев: сначала аудио-DSP (демодуляция FSK с учетом фазовых скачков), потом разбор формата кассеты (ZX TAP), потом реверс Z80-кода с ручным LCG-шифрованием и неочевидной раскладкой символов по экрану. Ни один слой сам по себе не был особо сложным, но пропустить любой из них значило не добраться до флага.

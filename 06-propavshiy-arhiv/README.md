# Пропавший архив

**Категория:** Cryptography
**Флаг:** `SOLARCTF{31a1e6f428f7b196ac1fe4}`

## Дано

Четыре экземпляра RSA-2048 с открытой экспонентой `e = 65537`. Для каждого экземпляра в условии давалась утечка верхних 518 бит из 1024-битного простого множителя `p` (или `q`, в зависимости от инстанса). Сам флаг был разбит на 4 куска по 8 байт, каждый кусок зашит в хвост 32-байтного зашифрованного сообщения.

## Идея атаки

Когда известна значительная старшая часть одного из простых множителей RSA-модуля, это классический сценарий для атаки Копперсмита (через лемму Howgrave-Graham): неизвестный "хвост" множителя представляется как корень небольшого многочлена по модулю `p`, и если утечка достаточно большая относительно размера числа, этот корень можно найти через LLL-редукцию решетки, без перебора.

В данном случае утечка 518 бит из 1024 означала, что неизвестных бит остается заметно меньше половины, но не впритык малых. Для надежности на каждый инстанс еще брутфорсились 4 дополнительных бита (16 вариантов), что гарантированно переводило оставшуюся неизвестную часть в комфортную для Копперсмита зону.

Формализуем это как `f(x) = a + x`, где `a` это известная старшая часть, а `x` малый неизвестный остаток, и ищем корень `f(x) ≡ 0 (mod p)` через решетку с параметрами `m = 27`, `t = 28` (итоговая размерность решетки около 55), с центрированием корня для лучшей сходимости редукции.

## Инструменты

Обычно для таких задач берут Sage, но на используемой машине (Windows, без WSL) ни Sage, ни fpylll, ни стандартный pwntools-стек под рукой не было. Выручил `python-flint`: он ставится через pip (есть готовые wheels даже под свежий Python) и предоставляет `fmpz_mat.lll()` для редукции решетки и `fmpz_poly.roots()` для поиска корней многочлена, что хватает для решеток размерности порядка 50-60.

На практике одна решетка такого размера считается около 2 минут в одном потоке, а если гнать все 16 вариантов брутфорса бит параллельно (по 4 бита на инстанс, то есть до 12 задач сразу), выходит порядка 8 минут на инстанс.

## Восстановление и сборка флага

После того как Копперсмит отдает недостающие биты, восстанавливается полное значение `p` (или `q`), дальше стандартно: `q = N / p`, вычисляется `phi`, приватная экспонента `d`, и обычное RSA-дешифрование. Повторяем для всех четырех инстансов, из каждого 32-байтного сообщения достаем последние 8 байт (хвост), и четыре хвоста подряд дают итоговый флаг.

## Вывод

Задача на то, что RSA с частичной утечкой множителя это не "защищенный" RSA, даже если формально числа огромные. Главный практический урок на будущее: для решеточных атак на Windows без Sage отлично выручает `python-flint`, он легкий, ставится без боли и справляется с решетками умеренного размера не хуже связки Sage + fpylll.
